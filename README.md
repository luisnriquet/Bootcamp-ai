# Bootcamp IA

## Proyecto 0: Clasificador de emails con IA
Clasifica emails por categoría y urgencia y devuelve JSON listo para integrar en un CRM o un helpdesk.

Problema: una pyme pierde cerca de 1 h al día haciendo triaje manual del correo.
Resultado: clasificación automática en segundos con resumen de una línea.

Cómo ejecutarlo:
1. pip install openai
2. Definir la variable GROQ_API_KEY
3. python classify.py

Stack: Python, API compatible con OpenAI (Groq), salida estructurada JSON.
